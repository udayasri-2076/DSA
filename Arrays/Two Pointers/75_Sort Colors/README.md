# Sort Colors - 75\n\n## Problem Statement\nGiven an array nums with n objects colored red, white, or blue, sort them in-place so that objects of the same color are adjacent, with the colors in the order red, white, and blue.\nWe will use the integers 0, 1, and 2 to represent the color red, white, and blue, respectively.\nYou must solve this problem without using the library's sort function.\n\n## Approach 1: Optimal (Dutch National Flag Algorithm)\n### Approach\nWe use three pointers (low, mid, and high) to partition the array into four regions in a single pass:\n- nums[0 ... low-1] contains 0s.\n- nums[low ... mid-1] contains 1s.\n- nums[mid ... high] contains unclassified elements.\n- nums[high+1 ... n-1] contains 2s.\n\n### Algorithm\n1. Initialize low = 0, mid = 0, and high = n - 1.\n2. Iterate while mid <= high:\n   - If nums[mid] == 0, swap elements at mid and low, increment both low and mid.\n   - If nums[mid] == 1, just increment mid.\n   - If nums[mid] == 2, swap elements at mid and high, decrement high.\n3. Terminate when mid > high, yielding a fully sorted array.\n\n### Time Complexity\nO(n) since we traverse the array at most once with the mid pointer.\n\n### Space Complexity\nO(1) because sorting is done entirely in-place.\n\n## Comparison of Approaches\n- Brute Force Approach: Standard sorting algorithms like Merge Sort or Quick Sort take O(n log n) time and O(n) or O(log n) space.\n- Better Approach: Counting sort takes two passes over the array to count frequencies and overwrite values, taking O(n) time and O(1) space.\n- Optimal Approach: The Dutch National Flag algorithm sorts the array in a single pass using O(n) time and O(1) auxiliary space.\n\n## Concepts Used\n- Arrays\n- Two Pointers\n- Dutch National Flag partitioning\n\n## Sample Input\nnums = [2, 0, 2, 1, 1, 0]\n\n## Sample Output\n[0, 0, 1, 1, 2, 2]
